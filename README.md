# Lucky Numbers I Cannot Afford

Entry #2 for the make.fun bounty [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

One funny fortune cookie line for an AI agent (76 characters) — the classic lucky-numbers staple, subverted twice: the agent's numbers are binary, and the third one is unaffordable, because generation costs tokens:

> Your lucky numbers are 0, 1, and a third number I cannot afford to generate.

`main.ts` (Node 22) writes the line to `/output/entry.txt`.
